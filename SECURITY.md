# Security & Intellectual Property Policy
## BJS & Bar Aspirants Academy

### 1. Proprietary Software Notice
All software, database designs, educational curriculum, and backend endpoints within this repository are the exclusive proprietary property of **BJS & Bar Aspirants Academy**. Unauthorized access, scraping, or database exfiltration is monitored and strictly prohibited.

### 2. Database Protection
- Database credentials, API tokens, and session secrets are strictly isolated to secure server-side environment variables (`.env`) and are **NOT** stored or committed to this repository.
- Anyone attempting unauthorized access to the database or attempting injection/penetration will be permanently IP blocked and reported to authorities.

### 3. AI & Automated Scraping Prohibition
Automated crawlers, AI scraping bots, and automated code-generation agents are forbidden from ingesting, scraping, or reproducing content from this repository without prior written authorization from the repository owner.
